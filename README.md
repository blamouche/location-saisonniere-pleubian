# Maison Od Joge — Site vitrine

Site web marketing pour la location saisonnière **Maison Od Joge**, maison familiale de 8 personnes à Pleubian (22610), Presqu'île sauvage, Côtes-d'Armor.

## Objectif

Créer un actif d'acquisition indépendant des plateformes : un guide de référence sur la Presqu'île sauvage, optimisé SEO et GEO (Generative Engine Optimization), avec une expérience visuelle qui change au fil des quatre saisons.

## État

📄 **Phase de cadrage** — le PRD est rédigé, l'implémentation n'a pas démarré.
